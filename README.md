# CODE128Project
Реализация кроссплатформенной библиотеки для генерации штрихкода типа code128

## Windows:  
cd C:\Users\Retro\source\repos\code128  
mkdir build  
cd build  
cmake .. -G "Visual Studio 17 2022" -A x64  
cmake --build . --config Release  

## Linux:  
cd /home/retro/code128  
mkdir build  
cd build  
cmake ..  
make  

## MacOS:  
cd /Users/retro/code128  
mkdir build  
cd build  
cmake ..  
make
